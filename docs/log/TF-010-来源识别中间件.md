## 决策记录
- **判定顺序**（QA 确认，与 §3.3 一致）：先回环分支，UI 凭据仅在回环内有效；非回环必须 Bearer。
- **needAuth 返回值设计**：Identify 返回 (Actor, needAuth)，由中间件决定 401——判定与响应解耦，便于单测与 MCP 复用。
- **actor 传递走 ctx**（QA P3-1 方案 A）：`WithActor/ActorFrom`，未写入兜底 unknown，安全默认。
- **api_token 空 → 远程 401**（QA 默认项 1）：不因"未配置密钥"而放行远程。
