## 决策记录
- **异步模型**：channel（缓冲 1024）+ 单消费者；满时回退同步写。理由：审计"不可篡改、保序"，宁可极端流量下短暂阻塞也不丢记录；业务路径正常不阻塞。
- **actor 显式传入**：`Write(ctx, workdir, e Entry{...})`，audit 包不 import auth（避免依赖纠缠），api 层组装时从 `auth.ActorFrom(ctx)` 取值。
- **action 命名对齐**：审计 action 直接复用业务层写钩子事件名（task.created 等），保证审计与 WS 事件同源可追溯。
- **Query 排序**：`ORDER BY id DESC`（插入序倒序）+ ts 兜底，保证同秒记录稳定。
- **导出格式**：`ts|actor|actor_class|action|target|result|detail` 含表头，响应体即导出物（不写盘，QA P3-8）。
