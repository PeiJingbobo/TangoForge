# docs/log — 任务日志

> 规则见 `AGENTS.md §13.3`：正式任务进行中，将工作过程（进展、决策、踩坑、验证）记录于此。
> **临时任务豁免**（§13.4）：修改配置文件、临时验证代码、纯只读操作等与修改源代码无关的任务，不需要日志。

## 命名规范

`TF-XXX-<任务标题>.md`（与总结同名、不同目录；同一任务跨多日按日期分节追加，禁止覆盖）。

## 日志模板

```markdown
# TF-XXX <任务标题> — 任务日志

## YYYY-MM-DD
- 进展：……
- 决策：……
- 踩坑：……（解决：……）
- 验证：命令 + 结果
```
