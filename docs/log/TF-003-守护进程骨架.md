# TF-003 守护进程骨架 — 任务日志

## 2026-08-06
- **进展**：完成 cmd/daemon 改造 + internal/api（server.go / middleware.go / server_test.go）+ db.ProjectExists。
- **决策**：
  - 单实例锁 = PID 文件（记录身份，退出删除）+ Server.Serve 端口 Listen 失败兜底（二次启动 bind 报错即拒），Windows 下不做进程存活探测（不引入 x/sys 直接依赖）。
  - 端口热重载：新端口先 Listen（失败保留旧端口）→ 替换 s.listener → 关闭旧 listener → 新 listener 由 http.Server 并发 Serve（官方支持多 listener）。
  - 中间件只挂 /api/*（/ping 裸奔）；X-Project 支持 Header 与 ?project= 两种方式（REQUIREMENTS §5.2）。
  - 错误响应统一 {code,message,detail}；业务码字符串（PROJECT_NOT_FOUND 等）。
- **踩坑（重要）**：
  1. **热重载导致 daemon 退出**：ReloadPort 关闭旧 listener → 主 Serve 返回 nil → main select 的 `case err := <-errCh: return err` 直接退出进程（新端口 20001 无响应）。修复：main 循环容忍 nil（mainServeDone 标记），仅真实错误退出，daemon 常驻由 ReloadPort 的新 listener 维系。
  2. **Windows Application Control 拦截 Temp 下测试 exe**：`fork/exec ...api.test.exe: blocked`（偶发/clean cache 后触发）。解决：`GOTMPDIR=C:/Users/PeiJingbo/.workbuddy/binaries/go/gotmp`（隔离目录）→ go test 正常。**此变量加入所有 go 命令前缀**。
  3. **Git Bash 无 sleep**：用 `ping -n N 127.0.0.1` 替代延迟。
  4. **rm -rf 被安全回收拦截**（genie-trash 相对路径问题）：清理临时目录用 PowerShell Remove-Item。
  5. **bash kill 对 Windows 原生后台进程不可靠**：清理 daemon 用 `taskkill /F /IM daemon.exe`。
- **验证**：单测 9/9；冒烟 5 项全过（ping 200 / 404 / 单实例 / 热重载 20001 / 进程存活）。
