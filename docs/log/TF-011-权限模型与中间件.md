### 2026-08-06（完成）

## 决策记录
- **中间件顺序**（QA 确认）：`workdir → identify → permission → handler`；测试中发现把 workdir 写入放 handler 侧会导致权限判断先于 workdir 就绪（500），修正为最外层写入。
- **denied 审计解耦**：`OnDenied` 回调注入，auth 包不直接依赖 audit 包（职责单一，api 层组装）。
- **全量覆盖**（QA P3-5）：Set 用 `ON CONFLICT ... DO UPDATE` upsert，事务内完成，未知 action 先校验拒绝。
- **缺失行/未知 action → denied**（QA 默认项 2）：`Allowed` 对 `sql.ErrNoRows` 返回 false。
- **Get 全量 16 项**（QA P3-6）：以 `project.AllActions` 为骨架，库内多余行忽略、缺失行 false。

## 踩坑记录
1. **测试链组装顺序**：初版 chain 把 workdir 写入放最内层，权限判断在 workdir 就绪前 → 4 个用例 500；修正后与 api 层真实顺序一致。
2. **cfg 值/指针**：`config.DefaultGlobalConfig()` 返回值传给 `IdentifyMiddleware` 需取地址（vet 直接报错）。
3. **网络磁盘 sed 不可用**：Windows 侧 sed 写临时文件 Permission denied，改用 Edit 工具批量替换。
