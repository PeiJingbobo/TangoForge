05 · 设计原则

四条铁律（编码时必须遵守）

01

少用卡片

只有内容需要独立成块、可点击、可复用、可对比时才用 Card。分组优先留白、标题层级、分割线、背景色差。

02

克制发光

渐变与 glow 只做少量强调，一次仅一处。不出现于背景、标题、按钮、边框、图标同时。发光仅表交互状态与层级深度。

03

实色文字

文字绝大多数使用实色，不用渐变。正文行高 1.5–1.7，标签可小但必须可读。层级靠字号字重而非颜色。

04

清晰阅读流

从标题 → 详情 → 操作按钮，路径直白。操作按钮固定在内容底部或视口底部，不悬浮于内容中间。

迁移提示（shadcn-ui / Tailwind）
  • 中性色：--background --foreground --muted --border --ring
  • 主色：--primary --primary-foreground（500/白）
  • 语义色：--success --warning --danger + soft 变体
  • 圆角：--radius 12–20px 级
Typography
  • text-display 40/48 · 700
  • text-h1 28/36 · 700
  • text-h2 21/28 · 650
  • text-body 15/24.6 · 400
  • text-caption 12/18 · 400
  • text-label 12.5 · 600

本文件为 M5 UI 设计基准的静态视觉参考。主色通过 CSS 变量整组切换（顶栏 4 个预设色点 + 彩虹取色器自定义，色阶与前景色按亮度动态计算），深色 token 已定义。正式实现时主色与明暗均可在程序内动态切换，并遵循系统 prefers-color-scheme。
