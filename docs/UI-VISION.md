# TangoForge — 原生应用窗口视觉要求与设计规范（UI-VISION）

> **版本**：v1.0（2026-08-06）
> **定位**：P5 前端应用（TF-022~028）的**视觉设计基线**。所有原生应用窗口（Electron GUI）界面的视觉决策以此为准。
> **文档优先级**：`docs/REQUIREMENTS.md` ＞ `AGENTS.md`（根目录权威）＞ `docs/TECHNICAL.md` ＞ **本文档**；冲突时以高优先级文档为准并向其登记。
> **配套文件**：`docs/design/visual-reference.html`（静态视觉参考 demo，配色板 / 排版标尺 / 组件形态 / 四个真实场景 / 动态取色与明暗切换，为本文档的**唯一参考实现**）。
> **范围外**：CLI 输出、MCP 工具文档、日志格式（无视觉面）。

## 2. 五项视觉要求（语义化与执行规则）

### 2.1 卡片使用铁律

> **需求原文**：减少卡片数量：只有内容需要独立成块、可点击、可复用、可对比时，才使用 Card 卡片组件；需要保证文字和背景之间拥有足够对比度。

**执行规则**：

1. **卡片资格判定（QA-1）**：四条件（独立成块 / 可点击 / 可复用 / 可对比）**任一满足**即具有使用卡片的资格，不必全部满足。
2. **信息量兜底（QA-1）**：单行可承载的信息（标题 + 2~3 个 meta，如项目列表行、属性字段行、文件行）**优先使用列表行（ListItem）**，禁止升级为卡片。卡片仅用于需要多行/多区块承载、且确实可点击/可拖拽/可对比的内容（如看板任务条目、复杂编辑块）。
3. **对比度标准**：正文文字与背景对比 ≥ **WCAG AA 4.5:1**；大字（≥24px）/图标 ≥ 3:1。卡片与所在区域之间可用细边框（1px）区分，不依赖深阴影。
4. **反例（禁止）**：信息分组不套卡片；表单字段不套卡片；`详情面板 = 卡片套卡片` 禁止。

### 2.2 分组手段（不用卡片时的分组方式）

> **需求原文**：普通信息分组不要套卡片，优先用：留白间距、标题层级、分割线、背景色差来做分组区分。

**执行规则**：

1. 四种分组手段按**信息距离就近选择，无强制优先级（QA-2）**：
   - **留白**：兄弟区块间 > 24px 间距；
   - **标题层级**：H2/H3 + eyebrow 眉题标示区块语义；
   - **分割线**：属性栏、字段组、列表分段（1px `--divider`）；
   - **背景色差**：仅用于**区域级**分组（看板列、侧栏、工具栏、操作底栏）。
2. **护栏一（禁叠用）**：同一信息分区内避免两种以上分组手段同时叠用（如「背景色差 + 分割线 + 卡片」三明治）。
3. **护栏二（色差限区域级）**：背景色差不用于细粒度分组（字段行、子任务），细粒度一律用分割线或留白。

### 2.3 渐变与 glow 克制

> **需求原文**：渐变和 glow（发光）只能作为少量强调色（accent），不要同时出现在背景、标题、按钮、卡片边框和图标上；发光效果仅用于表达交互状态或者层级深度。

**执行规则**：

1. **渐变白名单**（仅此三类，且同屏同时至多一处）：
   - 品牌 logo mark（`brand-mark`）；
   - 主按钮 hover 微光（可选，`box-shadow 0 0 20px primary/30`）；
   - 层级浮层（弹窗 / 抽屉投影，属阴影不算渐变）。
2. **glow 用途白名单**：仅表达**交互状态**（hover / focus-visible / 选中 / 拖拽目标）或**层级深度**（浮层）。禁止用于装饰。
3. **禁止**：渐变标题、渐变正文、glow 边框、渐变图标、背景大渐变。**一次界面只允许一处渐变或 glow 同时出现。**

### 2.4 实色文字与排版

> **需求原文**：文字绝大多数使用实色，不用渐变；拉大标题和正文之间的视觉差异；正文行高设置为 1.5–1.7；标签文字可以小，但必须保证可读。

**执行规则**：

1. 文字**一律实色**，禁止渐变文字 / 渐变标题。
2. **行高区间**：正文 1.5~1.7（基准 **1.64**）；标题 1.2~1.45（Display 1.20 / H1 1.30 / H2 1.35 / H3 1.45）。
3. **层级不靠颜色**：标题 / 正文 / caption / label 的区分主要靠字号、字重、行高与留白；颜色仅作辅助。
4. **标签下限**：caption / label 最小 **12px**（label 可 12.5px + 字重 600），保证小字可读；不得小于 12px。

### 2.5 阅读流（标题 → 详情 → 操作按钮）

> **需求原文**：能够建立从标题→详情→操作按钮的清晰阅读流。

**执行规则**：

1. **页面骨架**（详情页 / 弹窗统一）：`标题 → meta（状态/优先级/标签）→ 详情正文 → 子块（子任务/依赖）→ 操作按钮`，信息自上而下单向流动。
2. **操作按钮定位（QA-3）**：详情页 / 长内容弹窗的操作按钮固定在**视口底部（sticky footer）**，滚动时始终可见；浅层编辑（单字段改名、快速状态切换）用**行内浮层**，不占用底栏。
3. **主操作唯一**：一屏一个 primary 按钮；次要操作用 secondary / ghost，靠右排列；破坏性操作（删除、丢弃）为 danger，置于最左或明确分隔。
4. **属性栏**：任务详情右侧属性栏以「分割线分组」组织（基础字段 / 依赖标签 / 时间来源），不套卡片。

## 4. 设计 Token 基准（v1.0 定版摘要）

> 完整色板 / 排版对照见 `docs/design/visual-reference.html`（唯一参考实现）。以下为关键值，实现与 demo 不一致时以 demo 为准。

### 4.1 主强调色（可动态切换）

- **默认主色**：`#2292D8` 天蓝 Sky（500 级），主按钮文字为白（亮度 0.259）。
- **动态切换机制**：主色为 CSS 变量整组（`--primary-50` ~ `--primary-900`）；程序内切换时按以下算法计算色阶：
  - 浅色：500=所选色，50~400 向白混合（0.92/0.80/0.60/0.40/0.20），600~900 向黑混合（0.15/0.32/0.48/0.62）；
  - 深色：500 提亮 0.32，50~200 压暗作 soft 底，700+ 提亮作文字；
  - **前景色判定**：按 WCAG 相对亮度，> 0.35 用深字 `#16161A`，否则白字 `#FFFFFF`。
- 内置预设：`sky-blue #2292D8` / `forge-amber #E8912D` / `growth-green #2E9C66` / `ai-violet #7C66EC`（各含 light/dark 双色阶）。

### 4.2 中性色（zinc 系，无色相）

| 角色 | Light | Dark |
|------|-------|------|
| background 页面底 | `#FAFAFA` | `#17171A` |
| surface 浮层/表面 | `#FFFFFF` | `#1F1F23` |
| foreground 正文 | `#18181B`（17:1） | `#E4E4E7` |
| muted 分组底 | `#F4F4F5` | `#232327` |
| muted-foreground 次要文字 | `#71717A`（4.7:1） | `#A1A1AA` |
| border 边框 | `#E4E4E7` | `#2A2A2E` |
| divider 分割线 | `#ECECEF` | `#26262A` |

### 4.3 语义色（固定，不随主色；500 主色 + 50 soft 底 + 700 ink 文字）

| 语义 | 主色 | soft 底 | ink 文字 | Dark 主色 |
|------|------|---------|----------|-----------|
| success | `#22C55E` | `#F0FDF4` | `#15803D` | `#4ADE80` |
| warning | `#F59E0B` | `#FFFBEB` | `#B45309` | `#FBBF24` |
| danger | `#DC2626`（白字 4.83:1 达 AA） | `#FEF2F2` | `#991B1B` | `#EF4444` |

### 4.4 排版标尺

| 级别 | 字号/行高 | 字重 | 用途 |
|------|-----------|------|------|
| Display | 40/48 | 700 | Hero、空态大标题（慎用） |
| H1 | 28/36 | 700 | 页面标题（每页一个） |
| H2 | 21/28 | 650 | 任务标题、弹窗标题 |
| H3 | 17/25 | 600 | 分组小标题 |
| Body | 15/24.6（1.64） | 400 | 正文、任务描述 |
| Caption | 12/18 | 400 | 辅助说明、时间戳 |
| Label | 12.5/18.75 | 600 | 字段名、表头 |
| Button | 14/19.6 | 600 | 按钮文本（不小于正文太多） |

### 4.5 圆角 / 阴影

- 圆角：`--radius-sm 10px` / `--radius-md 14px` / `--radius-lg 20px` / `--radius-full 999px`（胶囊）。
- 阴影：日常界面不用；仅 hover 与浮层使用（`--shadow-card` / `--shadow-pop` 两档）。

## 5. shadcn-ui / Tailwind 映射

> token 落地文件：`app/src/styles/globals.css`（CSS 变量）；Tailwind 4 通过 `@theme` 引用变量。命名与 shadcn 惯例对齐。

| 本文档变量 | shadcn / Tailwind 映射 |
|------------|------------------------|
| `--background` / `--surface` | `background` / `card` + `card-foreground` |
| `--foreground` / `--muted-foreground` | `foreground` / `muted-foreground` |
| `--muted` / `--border` / `--divider` | `muted` / `border` / 新增 `divider` |
| `--primary-*` 色阶 + `--primary-foreground` | `primary` + `primary-foreground`（主按钮、链接、选中） |
| `--success/--warning/--danger` 三件套 | `success` / `warning` / `destructive` 扩展色 |
| `--radius-*` | `radius`（Tailwind `rounded-*`） |
| `--ring` / focus 软环 | `ring`（focus 用 3px `primary-100` 环） |

- **明暗**：`data-theme="light|dark"` + `prefers-color-scheme` 跟随系统；默认浅色优先。
- **主色切换**：`data-accent="sky-blue|...|custom"`；自定义主色由 JS 按 §4.1 算法动态写入 CSS 变量。
- **业务组件禁止硬编码色值**：一律通过变量 / Tailwind token 取色。

## 6. 每屏验收清单（UI 自检，开发完成与视觉评审共用）

- [ ] **卡片**：无多余卡片（单行内容未升级为卡片；信息分组未套卡片）
- [ ] **分组**：同一分区未叠用两种以上分组手段；背景色差仅出现在区域级
- [ ] **克制**：全屏渐变/glow 至多一处；glow 仅存在于交互态或浮层
- [ ] **文字**：实色无渐变；正文行高 1.5~1.7；caption/label ≥ 12px
- [ ] **对比度**：正文 ≥ 4.5:1，大字/图标 ≥ 3:1（用取色工具抽查 muted-fg 等弱对比场景）
- [ ] **阅读流**：标题 → 详情 → 操作按钮单向可达；操作按钮 sticky 底部常驻
- [ ] **主题**：浅/深双主题均无断色；主色切换后语义色不漂移
- [ ] **一致性**：色值/字号均来自 token（无硬编码）
