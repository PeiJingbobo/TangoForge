# TF-010 来源识别中间件 — 任务总结
> 结果：成功　|　日期：2026-08-06　|　执行人：ai

## 1. 任务范围
实现 `internal/auth` 来源识别核心：按 `docs/TECHNICAL.md §3.3` 的 5 级优先级判定请求来源（ui / agent / unknown），UI 凭据仅回环有效、远程无有效 Token 需 401；识别结果写入请求上下文供权限中间件与审计复用。

## 2. 交付内容
- **新增文件**：
  - `internal/auth/identify.go` — Actor 结构（Name/Class）、`Identify(cfg, r)` 5 级判定、`FromMCP(clientName)`（TF-016 用）、`WithActor`/`ActorFrom` 上下文传递（unknown 兜底安全默认）、回环判定
  - `internal/auth/token.go` — `secureEqual`（crypto/subtle 恒定时间比较，防时序侧信道）、`BearerToken` 提取
  - `internal/auth/identify_test.go` — 15 个用例覆盖 5 级判定全路径
- **关键实现点**：
  1. 优先级：回环+X-UI-Token 匹配 → ui；非回环 → 必须有效 Bearer（缺失/错误/api_token 未配置 → needAuth 401）；回环无 UI-Token → X-Actor 或 unknown
  2. **UI 凭据仅回环有效**：非回环携带正确 X-UI-Token 也无 Bearer → 仍 401（专项用例验证）
  3. **api_token 为空 → 远程一律 401**（安全默认，QA 确认）
  4. actor 经 ctx 传递（`WithActor`/`ActorFrom`），业务层写钩子（TF-012/014）统一从 ctx 读取，识别一次全链路可用
