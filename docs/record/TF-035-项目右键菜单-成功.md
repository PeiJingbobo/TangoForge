# TF-035 项目右键菜单 — 任务总结

> 结果：成功　|　日期：2026-08-07　|　执行人：ai

## 1. 任务范围
全局导航栏项目列表项右键菜单，提供三项功能：重命名、删除项目、在文件夹中打开。

## 2. 交付内容
**后端（Go）**
- `internal/project/project.go`：`Rename(ctx, id, name)`——仅改 `projects.name` 行
  （去首尾空白，空名拒绝；不触碰磁盘与 workdir；回读更新后记录返回）；测试 3 例
- `internal/api/handlers_projects.go`：`PATCH /api/projects/:id` 重命名（仅 UI，
  同删除权限语义：agent/远程 403；空名 → `TASK_INVALID` 422；不存在 → 404）；
  审计 `project.renamed`（按 workdir 写项目库）；`internal/api/server.go` 注册路由
- API 测试 1 例（agent 403 / UI 200 回显新名 / 列表反映 / 空名 422 / 404）

**Electron**
- `app/electron/daemon.ts`：`shell:revealPath` IPC——目录存在 `shell.showItemInFolder`
  （系统文件管理器中选中该目录），不存在 `shell.openPath` 打开上级兜底
- `app/electron/preload.ts`：白名单暴露 `tangoforge.shell.revealPath(path)`

**前端（React）**
- `app/src/components/ui/context-menu.tsx`：新增 shadcn context-menu 组件
  （@radix-ui/react-context-menu，样式对齐 dropdown-menu：popover/shadow-pop/动画）
- `app/src/components/layout/app-layout.tsx`：项目列表项包裹 ContextMenu 右键菜单——
  「重命名」（Dialog + Input + Enter 提交）/「在文件夹中打开」（Web 环境 toast 提示仅桌面版）/
  「删除项目」（二次确认 Dialog；删除当前项目清空全局项目态）；`useRenameProject` hook
- 测试 +3：重命名 PATCH 调用断言 / 删除二次确认 + DELETE / Web 环境打开文件夹提示不可用

## 3. 验证结果
- Go 全仓全绿（project +3、api +1）；前端 150 用例全绿（+3）；typecheck / lint / electron build 通过
- daemon 实测：agent 重命名 403 / UI 200 / 列表反映新名称；测试项目清理
- gofmt 干净；`CGO_ENABLED=0 go build` 通过

## 4. 遗留问题与后续

- 重命名只影响显示名，若需同步修改磁盘目录名需额外确认流程（当前明确不做）
