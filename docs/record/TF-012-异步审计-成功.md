# TF-012 异步审计 — 任务总结
> 结果：成功　|　日期：2026-08-06　|　执行人：ai

## 1. 任务范围
实现 `internal/audit` 异步审计：audit_log 表（项目库）异步写入（不阻塞业务）、查询与导出能力；扩展业务层写钩子签名（QA P3-1 方案 A：携带 workdir），为 TF-014 WS 事件复用同一钩子。

## 2. 交付内容
- **新增文件**：
  - `internal/audit/audit.go` — `Store`（channel 1024 + 单消费者 goroutine）：`Write`（非阻塞投递，满则回退同步写保序不丢）/ `Query`（filter[actor]/[action] + 分页，默认 100 上限 500，ts 倒序）/ `Export`（audit.log 文本，行格式 `ts|actor|actor_class|action|target|result|detail` 含表头）/ `Close`（排空队列）；连接缓存与 task/auth 分离
  - `internal/audit/audit_test.go` — 9 用例
- **修改文件**（写钩子签名扩展）：
  - `internal/task/service.go`：`WriteHook` 改为 `func(ctx, workdir, action, target)`；`emit` 同步扩展；3 处调用补 workdir
  - `internal/task/archive.go`：3 处 emit 补 workdir（task.archived/restored/deleted）
  - `internal/task/state_machine.go`：1 处 emit 补 workdir（state_machine.changed，target=workdir 语义不变）
  - `internal/task/service_test.go` / `archive_test.go` / `state_machine_test.go`：4 处 OnWrite 回调签名同步
- **关键实现点**：
  1. **异步不阻塞**：channel + 消费者 goroutine；Write 批量 1000 条 < 1s 验证
  2. **可靠性**：channel 满回退同步写（保序不丢）；Close 排空剩余队列（专项用例验证落库 10/10）
  3. **actor 来源**：由调用方显式传入（api 层经 auth.ActorFrom 读取），audit 包不依赖 auth（职责单一）
  4. **只追加**：Store 无更新/删除方法（表不可篡改约束）
  5. 审计 action 与写钩子事件名对齐（task.created 等）；denied 记录由权限中间件 OnDenied 回调写入（TF-013 组装）
