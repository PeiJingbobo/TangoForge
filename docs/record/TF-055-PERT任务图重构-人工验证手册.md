# TF-055 PERT 任务图重构 — 人工验证手册

> 适用版本：2026-08-18 工作区
> 目标：验证自动化测试无法覆盖的真实 Electron 视觉、鼠标交互与复杂依赖可读性。
> 完成判定：以下必验项全部通过后，TangoForge TF-028 才可从 `verifying` 流转 `done`。

## 1. 准备

在 Mac 终端执行：

```bash
cd /Volumes/HD-DATA/Coding/TangoForge
pnpm dev
```

打开 TangoForge 项目，进入“全景图”，确认右上角选择“PERT 图”。建议窗口宽度不低于 1440px。

## 2. 必验项

### A. 圆形节点与依赖方向

1. 确认任务节点均为圆形，不再显示为矩形卡片。
2. 圆内可看到任务编号，圆下可看到任务标题；悬停时系统 tooltip/`title` 可读完整内容。
3. 状态颜色与看板状态颜色一致。
4. 节点左上角不再出现额外的状态指示点。
5. 依赖箭头全部从左指向右，未出现反向箭头。

通过标准：节点不重叠，编号可辨认，任务标题不会遮挡相邻圆形节点或主依赖线。

### B. 共享初始端点

1. 找到一个具有至少 3 条后续依赖的任务（例如 TF-005 或 TF-013 附近）。
2. 放大到 100%–150%。
3. 检查多条贝塞尔曲线是否从圆右侧同一个端点出发，并共享初始切线后自然分叉。

通过标准：同一节点右侧不再出现多个上下分散的端口；共享主干清晰且未覆盖节点文字。

### C. 路径选择与溯源

1. 点击任意依赖线的中段。
2. 确认所选线变粗但保持所属根任务谱系颜色；两端节点出现主色外环。
3. 确认连接线上没有矩形焦点框或选中框。
4. 确认源端的全部上游任务和依赖线保持高亮。
5. 确认目标端的全部下游可达任务和依赖线保持高亮。
6. 确认无关任务与旁路线明显变淡。
7. 点击“清除路径”或画布空白，确认恢复全图。
8. 使用 Tab 聚焦一条边，按 Enter/空格，确认键盘也可选择/取消且不出现矩形框。

通过标准：选择态能够清楚回答“从哪里来、接下来能去哪里”，且不会把无关旁路误高亮。

### D. 画布平移与缩放

1. 首次进入 PERT 图，确认节点以可读的局部尺度出现，而不是把 47 个节点压成一个很小的全图缩略图。
2. 确认画布高度随窗口增高而增大；缩放窗口后重新进入页面，仍至少保留可操作区域。
3. 在画布空白处按住鼠标左键，持续向四个方向拖动；将图拖到可视区外再拖回，确认没有平移边界卡死或浏览器文本选择。
4. 拖拽和缩放时观察点阵，确认点阵与节点/连接线同步移动和缩放，没有固定在屏幕上的“玻璃背景”感。
5. 滚轮连续缩小至全图，再放大到节点细节。
6. 将鼠标停在空白点阵区域，确认指针为抓手；再移到任意连接线上，确认切换为普通箭头；离开连接线后恢复抓手。
7. 对比 25%、100%、200% 三档，确认线宽与箭头跟随画布一起缩放，没有始终保持屏幕固定大小。
8. 点击“适应屏幕”，确认整张逻辑图居中并完整进入可视区域；此操作与首次进入的局部可读视图明显不同。
9. 放大后拖拽到最右侧/最下侧，确认可访问末层任务。

通过标准：拖拽连续，无明显跳变；缩放范围足够；“适应屏幕”不是简单回到左上角。

### E. 复杂关系可读性

1. 使用 TangoForge 当前真实项目（约 47 节点、多个跨层依赖）。
2. 重点检查 TF-005、TF-013、TF-029/030 周边的高出入度区域。
3. 等待进入页面后的异步布局稳定，确认节点明显疏离、非连通分量之间有额外留白，没有互相拥挤或重叠；不要求节点机械对齐。
4. 确认连接线均为平滑三次贝塞尔；多段 B 样条的连接处没有横平竖直折角、尖角或锯齿。
5. 找到至少两个根任务，确认它们使用不同线路色；沿各自后代追踪，确认谱系内线路颜色一致。
6. 检查高密度区域不存在可由节点换序避免的明显交叉；当前真实图为非平面图，对不可避免的交叉逐条选线仍应能辨认完整路径。
7. 检查所有跨越多个层级的长依赖，确认它们改走节点间安全走廊，没有穿过任何圆形节点或标题。
8. 定位 TF-050 → TF-051，确认两个节点基本处于同一水平线，连接线没有斜跨 TF-030、TF-035 等末层节点。
9. 在全图缩放状态下寻找两条原本共用底部或顶部走廊的长依赖，确认它们现在使用不同高度或不同弯曲幅度，不再整段重合。
10. 选择一条横跨内部密集连接区的长边，确认它优先绕到内部网络上方或下方，再以宽缓弧线回到目标；沿途没有直角折点。
11. 放大检查多段曲线的连接位置，确认曲线切线连续，没有尖角、突然变向或短小锯齿。
12. 检查 TF-029、TF-030 等高入度目标附近：多条入边可以在箭头前自然汇聚，但不应从远处提前合并成一条线。
13. 放大任意一条包含多个曲线段的长依赖，沿整条路径缓慢查看，确认每个内部连接点的方向连续，没有可见折角或突然变平。
14. 比较相邻两层节点，确认左右净距明显大于上一版；同层节点可轻微左右错落，不应呈现严格网格。

通过标准：任意连接线都不穿过非端点圆形节点；未选择时整体比旧截图整洁，根谱系可凭颜色追踪；长边平滑绕开节点；选择任意线后，其完整上下游路径可稳定辨认。边交叉以明显减少和可追踪为准，不以数学上不可能的绝对零交叉作为判定。

### F. 搜索路径与自动聚焦

1. 先选中任意一条与 TF-020 无关的依赖线，再在搜索框输入 `TF-020`。
2. 等待约 300ms，确认旧的边选择提示消失，TF-020 保持高亮。
3. 检查 TF-020 节点外侧，确认出现与节点同心、使用主色描边且与主体有明显间隙的圆形标记。
4. 确认只有通向 TF-020 的上游溯源路径，以及从 TF-020 出发的下游可达路径保持高亮。
5. 检查其他连接线及其箭头，确认同步降至很低的透明度，不再以正常谱系色抢占视觉焦点。
6. 点击画布点阵背景，确认全部节点和连接线恢复普通对比度，但搜索框仍为 `TF-020`，TF-020 外侧同心圆仍然存在。
7. 修改为另一个搜索词，确认相关路径重新进入高亮状态，新的命中节点显示同心圆。
8. 搜索一个会命中多个任务的标题关键词，确认画布自动平移和缩放，所有命中节点均完整出现在可视区域内，并分别带有同心圆。
9. 搜索一个唯一任务编号，确认结果大致居中、标题完整可见，且不会被过度放大。
10. 输入不存在的任务编号，确认画布不突然跳回其他区域。

通过标准：搜索结果、相关路径和视口聚焦同步完成；背景点击只清除临时高亮，不清除结果标记；旧选边和无关路径不会污染当前搜索上下文；多结果无遗漏。

### G. 回归

1. 单击节点，确认打开任务抽屉。
2. 双击节点，确认进入任务详情路由。
3. 切换到“力导向”，确认旧视图仍可用；再切回 PERT，确认偏好被记住。
4. 切换深色主题，确认节点、线条、点阵背景和选中态仍有足够对比度。
5. 选中一条路径，放大检查无关路径的箭头，确认其透明度与无关线条一致，不再以高亮颜色悬浮在淡化线路末端。

### H. ARGUS 层级任务回归

1. 使用包含本修复的新构建启动 macOS App，选择项目 `ARGUS`，进入“全景图 → PERT 图”。
2. 确认首次进入后立即能看到一个高分支根任务及其向右展开的后代，而不是只有点阵空白背景。
3. 确认父任务到子任务之间存在可见连接线；没有 `depends_on` 的纯层级任务也不能消失或全部堆在同一层。
4. 点击“适应屏幕”，确认 141 个节点能够进入全图概览；随后放大并拖回主根区域，确认无限画布可正常浏览。
5. 在父子线中选择一条，确认命中、上下游高亮、箭头缩放和背景点击清除行为与依赖线一致。
6. 切换到“力导向”再切回 PERT，确认不会再次出现空白，且视图偏好正常保存。

通过标准：ARGUS 首屏可见主根及层级分支，父子关系参与布局和交互；全图概览、缩放、平移均可用。该部分必须在真实 macOS App 中人工执行，自动化测试不能替代。
