# docs/record — 任务总结归档

> 规则见 `AGENTS.md §13.2`：每个正式任务完成后，必须在此创建任务总结。

## 命名规范

`TF-XXX-<任务标题>-<结果>.md`

- `TF-XXX`：任务编号（见 `docs/task/TASKS.md`）
- `<任务标题>`：与任务清单一致的简短标题
- `<结果>`：`成功` / `失败` / `部分完成`

示例：`TF-001-数据库迁移脚本-成功.md`

## 总结模板

```markdown
# TF-XXX <任务标题> — 任务总结
> 结果：成功 / 失败 / 部分完成　|　日期：YYYY-MM-DD　|　执行人：<ai|human>

## 1. 任务范围
## 2. 交付内容
## 3. 验证结果
## 4. 遗留问题与后续
```
