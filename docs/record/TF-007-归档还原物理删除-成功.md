  2. 级联置空（Q3/Q8-A）：仅直接子任务置空为顶层（孙任务不受影响），`ChildrenCleared` 返回数量供 UI 确认；归档/删除 + 置空同一事务原子

  5. 依赖提示（Q1-A）：`DependentCount` = 未归档任务依赖数，不阻断归档
