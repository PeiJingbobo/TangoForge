# TF-024 项目管理界面与守护进程集成 — 任务总结

> 结果：成功　|　日期：2026-08-06　|　执行人：ai

## 1. 任务范围
Electron 主进程 daemon 集成（探活/拉起/token 注入）+ 工作区项目列表/导入界面。

## 2. 交付内容
- `electron/daemon.ts` 实装：GET /ping 探活（800ms 超时）→ spawn daemon（TANGOFORGE_DAEMON env → 打包 resources/bin → 仓库 bin/ 查找；detached+unref 退出不关）→ 轮询 ≤5s；readUiToken 正则解析 `~/.taskboard-app/config.yaml`；dialog:selectDirectory IPC
- `electron/main.ts` / `preload.ts`：注册白名单 IPC（daemon:ensureRunning / config:readUiToken / dialog:selectDirectory）
- `lib/bootstrap.ts`：App 启动 ensureDaemon + 注入 ui_token（web 模式守卫）
- `WorkspacePage.tsx` 实装（UI-VISION 场景 A）：左侧行式项目列表（hover/移除）+ 右侧空态引导/概览；导入=目录选择器（electron）或手动路径兜底（web）→ POST /api/projects/import（后端语义确认：未注册目录自动初始化 .taskboard/ 全套）→ setProject + 跳转看板；4 个 RTL 测试
- `AppLayout`：显示当前项目名胶囊 + 导航精简
