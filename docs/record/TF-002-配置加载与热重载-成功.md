# TF-002 配置加载与热重载 — 任务总结
> 结果：成功　|　日期：2026-08-05　|　执行人：ai

## 1. 任务范围
交付 `internal/config` 双层配置模块：全局配置（`~/.taskboard-app/config.yaml`）与项目配置（`{workdir}/.taskboard/config.yaml`）的默认值、加载、合并、保存，以及基于 fsnotify 的全局配置热重载。

## 2. 交付内容
- **新增文件**：
  - `internal/config/config.go` — 类型定义（GlobalConfig / LLMConfig / ProjectConfig / StateMachine / State / Transition / ExportConfig）+ 路径工具（GlobalConfigPath / ProjectConfigPath）
  - `internal/config/global.go` — 默认值、LoadGlobal（缺失容错 + 解析失败报错）、SaveGlobal（0600 保护凭据）、GenerateToken（crypto/rand hex）、WatchGlobal（fsnotify 热重载：监听目录兼容原子保存 + 150ms 去抖 + 失败保留旧配置）
  - `internal/config/project.go` — DefaultStateMachine（todo/doing/done + 3 条 transitions）、DefaultProjectConfig、LoadProject / SaveProject（states 空时回退默认状态机）
  - `internal/config/config_test.go` — 13 个测试用例
- **新增依赖**：`gopkg.in/yaml.v3 v3.0.1`（纯 Go；Q3 依赖范围外的新增项，用于 YAML 解析）
- **关键实现点**：
  1. 双层分离：全局配置只管安全/端口/LLM，项目配置只管 state_machine/export，互不混淆（AGENTS.md §2.3）
  2. WithDefaults 补齐零值字段（端口、LLM 超时/重试/4096/并发）
  3. 热重载监听目录而非文件，兼容编辑器「临时文件 + rename」保存；事件 150ms 去抖合并
  4. 热重载失败保留旧配置并记日志（不中断 watcher）；回调由 TF-003 消费（端口重绑 / remote_access 切换）

- WatchGlobal 仅对全局配置生效；项目配置（state_machine/export）为启动时加载，无需热重载（修改后重导项目或重启生效，符合需求范围）。
