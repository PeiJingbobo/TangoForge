# TF-003 守护进程骨架 — 任务总结
> 结果：成功　|　日期：2026-08-06　|　执行人：ai

## 1. 任务范围
交付守护进程常驻骨架：单实例锁、健康检查（/ping）、来源过滤中间件、X-Project 注册校验、端口热重载，并接入 TF-001/TF-002 的数据库与配置能力。

## 2. 交付内容
- **新增/修改文件**：
  - `cmd/daemon/main.go`（改造）— 移除 --workdir 必填（QA Q5 多项目模式）、ui_token 首启生成持久化、PID 文件、注册表库初始化、WatchGlobal 热重载接入、服务生命周期管理
  - `internal/api/server.go` — Server（chi 路由、当前配置原子读、Serve/ReloadPort 端口重绑、Alive、Shutdown、统一 JSON 响应）
  - `internal/api/middleware.go` — remoteAccessMiddleware（非回环 + !remote_access → 403）、projectMiddleware（X-Project 缺失/未注册 → 404 PROJECT_NOT_FOUND）
  - `internal/api/server_test.go` — 9 个测试（含真实监听 + 端口热重载集成测试）
  - `internal/db/db.go` — 新增 `ProjectExists` 原生 SQL 查询（中间件与 TF-004 共用）
- **关键实现点**：
  1. 单实例锁：PID 文件记录身份 + Server.Serve 端口占用检测兜底（二次启动 bind 失败即拒）
  2. 来源过滤与端口重载共用「当前配置原子副本」（SetConfig/currentConfig），remote_access 热切换免重启
  3. ReloadPort：新端口先 Listen（失败保留旧端口）→ 替换 listener → 旧 listener 关闭；http.Server 多 listener 并发服务
  4. /api/* 中间件链：remoteAccess → project（X-Project 头或 ?project= 查询参数）
