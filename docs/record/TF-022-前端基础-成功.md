### 环境关键决策
- **前端工具链迁移到 macOS 侧执行**（与 Go 工具链同一模式）：Windows 侧对共享盘（SMB）跑 pnpm 连续失败——① WorkBuddy safe-delete shim 拦截 UNC 路径删除（`NODE_OPTIONS=--require=genie-safe-delete`，可用 `NODE_OPTIONS=` 清空绕过）；② hoisted 模式 `.bin` 链接缺失；③ caniuse-lite 等大量小文件 scandir 失败（SMB 不稳）。macOS 本地盘无此问题。
- macOS 环境：`~/node-sdk`（node v22.22.2 darwin-arm64，npmmirror 下载）+ corepack pnpm@9.15.0（COREPACK_NPM_REGISTRY=npmmirror）；electron 镜像 ELECTRON_MIRROR。
- shadcn CLI 组件源（ui.shadcn.com registry）国际网络 TLS 失败 → **手动写标准 new-york 组件 + pnpm add radix 原语**（npmmirror 可用）。
- node_modules 在共享盘 hoisted（根 `node_modules/`），macOS 侧安装为 darwin 平台二进制；Windows 侧后续跑 vite build 需补装 win 二进制（P6 处理）。
