## D. LLM 导入草稿流（真实 DeepSeek，可选但强烈建议）

1. 配置 LLM（二选一）：
   - 环境变量：`export DEEPSEEK_API_KEY=<你的 key>`（llm 客户端自动回退读取）
   - 或写入全局配置 `~/.taskboard-app/config.yaml`：
     ```yaml
     llm:
       base_url: "https://api.deepseek.com"
       api_key: "<你的 key>"      # 或留空走环境变量
       model: "deepseek-v4-flash"
       api_kind: "openai"         # openai | anthropic | responses
       timeout_sec: 60
       retries: 1
       max_tokens: 4096
       concurrency: 1
     ```
   > 注：`api_kind: anthropic` 时 base_url 填 `https://api.deepseek.com/anthropic`（DeepSeek 兼容端点）。
2. 导入（CLI）：
   ```bash
   ./bin/tangoforge import preview --project <目录> --file <你的 markdown 文档.md>
   ./bin/tangoforge import drafts --project <目录>
   ./bin/tangoforge import confirm <draft-id> --project <目录>
   ./bin/tangoforge tasks list --project <目录>
   ```
   预期：草稿 → 确认后任务入库（含 source_file/source_section、优先级/标签/状态映射）。
3. 导出往返：
   ```bash
   ./bin/tangoforge export --project <目录> --target copy
   # 查看 <目录>/.taskboard/export.md；可再将其 import preview → 往返一致
   ```
4. LLM 生成模板：
   ```bash
   ./bin/tangoforge export template <示例文档.md> --project <目录>
   ./bin/tangoforge export --project <目录> --template-mode llm --target copy
   ```
   > 失败分支预期：LLM 未配置 → 422 LLM_NOT_CONFIGURED；解析失败 → 422 IMPORT_FAILED（detail 含 LLM 原始输出）。
