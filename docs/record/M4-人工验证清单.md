## D. LLM 导入草稿流（真实 DeepSeek）

> ✅ **AI 已执行（2026-08-06，项目 `01`）**：目录模式 `import preview --dir <目录>/docs` 一次解析 5 任务（含"高优先级"→priority=4 语义理解）→ `import drafts` 可查 → `import confirm` 入库 5 任务。以下为完整复现步骤。

1. 配置 LLM（二选一，**推荐直接写配置文件**）：
   - ⚠️ 环境变量方式注意：**daemon 是长驻进程，环境变量是启动时快照**——shell 里 `export DEEPSEEK_API_KEY=...` 对**已运行**的 daemon 无效；必须 `export` 后**重启 daemon** 才生效（或直接写配置文件，fsnotify 热重载即时生效）。
   - 写入全局配置 `~/.taskboard-app/config.yaml`：
     ```yaml
     llm:
       base_url: "https://api.deepseek.com"
       api_key: "<你的 key>"      # 推荐直接填写（热重载即时生效）
       model: "deepseek-chat"     # ⚠️ 结构化解析建议用非推理模型（deepseek-chat）；推理型（deepseek-v4-flash）会因推理 token 耗尽 max_tokens 导致 content 为空（LLM_TRUNCATED）
       api_kind: "openai"         # openai | anthropic | responses
       timeout_sec: 120           # DeepSeek 首次调用可能较慢，建议 ≥60
       retries: 1
       max_tokens: 8192          # ⚠️ 大文档需 ≥8192（实测 94 任务文档需 8k；不足报 LLM_TRUNCATED）
       concurrency: 1
     ```
   > 注：`api_kind: anthropic` 时 base_url 填 `https://api.deepseek.com/anthropic`（DeepSeek 兼容端点）。
2. 导入（CLI，支持单文件/多文件/目录**一次解析**）：
   ```bash
   # 单文件
   ./bin/tangoforge import preview --project <目录> --file <你的 markdown 文档.md>
   # 多文件（合并为一次 LLM 解析，source_file=公共父目录）
   ./bin/tangoforge import preview --project <目录> --file a.md --file b.md
   # 目录（递归扫描 *.md/*.markdown 后合并解析，source_file=目录，推荐）
   ./bin/tangoforge import preview --project <目录> --dir <文档目录>

   ./bin/tangoforge import drafts --project <目录>
   ./bin/tangoforge import confirm <draft-id> --project <目录>
   ./bin/tangoforge tasks list --project <目录>
   ```
   预期：草稿 → 确认后任务入库（含 source_file/source_section、优先级/标签/状态映射；多文件/目录的 source_file 为公共父目录/目录）。
   > 提示：CLI 超时已放大到 120s；**LLM 调用不随客户端断开取消**——若网络慢导致 CLI 超时，稍后 `import drafts` 仍能查到草稿（服务端已继续完成）。
3. 导出往返 — **待用户执行**：
   ```bash
   ./bin/tangoforge export --project <目录> --target copy
   # 查看 <目录>/.taskboard/export.md；可再将其 import preview → 往返一致
   ```
4. LLM 生成模板 — **待用户执行**：
   ```bash
   ./bin/tangoforge export template <示例文档.md> --project <目录>
   ./bin/tangoforge export --project <目录> --template-mode llm --target copy
   ```
   > 失败分支预期：LLM 未配置 → 422 LLM_NOT_CONFIGURED；解析失败 → 422 IMPORT_FAILED（detail 含 LLM 原始输出）。
