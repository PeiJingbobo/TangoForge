## 5. 进度追踪方法

1. **唯一事实源**：任务状态以 `docs/task/TASKS.md` 为准，本文件为镜像展示，两处必须同步更新。
2. **更新时机**：任务开始（⬜→🔵）、完成（🔵→✅）、受阻（🔵→⛔，注明原因）时更新；同时更新「§1 统计」与「§2 泳道」。
3. **分支命名**：`feat/TF-XXX-<slug>` / `fix/TF-XXX-<slug>`，提交信息带任务编号（见 MASTER-PLAN.md §5.1）。
4. **完成闭环**：任务 ✅ 必须伴随 `docs/record/TF-XXX-<标题>-<结果>.md`（总结）与 `docs/log/TF-XXX-<标题>.md`（日志）；缺记录的"完成"视为未完成。
5. **定期复盘**：每个里程碑达成后，对照 MASTER-PLAN.md §7 质量门禁逐项打勾，未达标不进入下一阶段。
