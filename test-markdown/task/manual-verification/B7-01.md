# B7-01 人工验证手册

## 1. 元数据

- 任务 ID：B7-01
- 任务标题：设置页固定侧边栏与最后窗口关闭自动退出
- 关联开发计划：步骤一、第五节设置界面规格、最终完成定义
- 手册状态：待执行
- 最近更新日期：2026-08-01

## 2. 验证目标

验证设置窗口具有始终可见、不可折叠的左侧分类栏；各设置项仍能正确操作；当且仅当最后一个应用窗口关闭时，Farframe RDP 进程自动退出。

## 3. 前置条件

- 使用本任务代码构建的 Debug 或本地签名应用。
- Mac 处于已解锁、已登录的图形会话。
- 不需要 Windows 主机、RDP 凭据、证书或网络测试数据。
- 记录截图时只截取设置界面，不显示真实连接 Profile、账号、主机或其他个人信息。
- 记下测试前“自动检查可达性”的开关状态，清理时恢复。
